The terryheath.com Ghost theme is stock Dawn 1.0.0 plus one added file, `podcast.hbs` (the /podcast/ index; `routes.yaml` (in this folder) points the /podcast/ collection at it with `template: podcast`).
To change it: download the active theme in the Ghost admin session (`GET /ghost/api/admin/themes/dawn/download/`), add or replace the file in the zip, and upload it as `dawn.zip` (`POST /ghost/api/admin/themes/upload/`). The Admin API integration key cannot do theme calls, only the signed-in session can.

The subscribe icons on /podcast/ (Apple Podcasts, Spotify, YouTube, Amazon Music, iHeartRadio, Deezer, RSS) are the same pills, SVG icons, colors, links and order as Inkhorn's old Life on Words page (from its footer code injection, saved in `inkhorn/theme/rollback/ghost_foot.txt`), with their styles inline in `podcast.hbs`. The YouTube pill is the playlist link `youtube.com/playlist?list=PLCszJw8y8GcM`; the channel `@lifeon_words` still carries the old name "Life on Words".

`guest-guide.hbs` (added 2026-11-15) renders the Life on Words guest guide: the public page with slug `guest-guide` is served at /podcast/guests/ by a route in `routes.yaml` (`data: page.guest-guide`, `template: guest-guide`). The page's own code injection holds its styles; its headshot form posts the image to `https://admin.terryheath.com/podcast/headshot?g=<guest token>` (see `inkhorn/podcast-routes.cjs`). /podcast/ has a small "For guests" link under the subscribe icons.
