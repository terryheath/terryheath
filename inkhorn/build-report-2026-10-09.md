## Theme (version 1.1.0, deployed)

Added: `edition.hbs`, `partials/edition-hero.hbs`, `partials/edition-contents.hbs`, `partials/edition-item.hbs`, `partials/editions/autumn-2026.hbs`, `partials/editions/winter-2026.hbs`.
Changed: `home.hbs` (catalog query now `order="published_at desc"`, hero and contents via partials), `assets/css/inkhorn/inkhorn.css`, `package.json`.

Two choices to know about:
- Each line of the running-order files has its own literal `{{#get}}`, which the plan allowed; I did not need to test partial-parameter interpolation. The files are generated by `inkhorn/scripts/gen-edition-partials.cjs`.
- Ghost's `{{#has tag=}}` matches tag names, not slugs, so `edition-contents` matches the season tag by slug with `{{#match}}`. Catalog pages are fetched with `include="tags"`.

Checked on the live home page: 25 numbered lines, every one linked, staff line underneath.
